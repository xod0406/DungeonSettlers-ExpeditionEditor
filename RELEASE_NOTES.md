# Dungeon Settlers Expedition Editor v2.1.6

This release restores Expedition Editor compatibility with **Dungeon Settlers DS_B.0.4.23**.

The previous v2.1.5 compatibility attempt failed safely at startup because its native talent patch addresses were incorrect. v2.1.6 corrects those seven addresses and keeps the established v2.1.4 character-editing and save/load behavior unchanged.

## Install

Copy the included `BepInEx` folder into the Dungeon Settlers installation directory, then press **F4** in game to open the editor.

## Important

- Target game version: **DS_B.0.4.23**
- Existing config files are preserved.
- Do **not** select the unfinished `Lumberjack` background.
